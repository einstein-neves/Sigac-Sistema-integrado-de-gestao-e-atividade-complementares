2. COMO RODAR O SIGAC WEB/PWA

Na raiz do projeto, onde ficam server.js, db.js e package.json, execute:

npm install
npm start

Ou, se existir package-lock.json e o professor pedir instalação limpa:

npm ci
npm start

Acesse no navegador:

http://127.0.0.1:3000

ou:

http://localhost:3000

3. CONFIGURAÇÃO DO .ENV

O SIGAC usa PostgreSQL. O arquivo db.js exige a variável DATABASE_URL.

Crie um arquivo chamado .env na raiz do projeto com uma linha semelhante a:

DATABASE_URL=postgresql://USUARIO:SENHA@HOST:PORTA/NOME_DO_BANCO?sslmode=require
PORT=3000

Observações:
- O arquivo .env não deve ser enviado para GitHub ou para pessoas fora do grupo.
- Se o erro "Defina a variavel de ambiente DATABASE_URL" aparecer, o .env está ausente ou a variável está incorreta.
- Se aparecer erro de módulo faltando, rode npm install ou npm ci.

5. ORGANIZAÇÃO DO ML ATUAL

O ML atual funciona com este fluxo:

data/raw
→ scripts/limpar_dados.py
→ data/processed/dataset_limpo.csv
→ scripts/gerar_relatorio_ml.py
→ reports/resumo_executivo.txt e reports/resumo_metricas.csv
→ scripts/treinar_modelo.py
→ reports/risco_alunos.csv e models/modelo_risco_aluno.json

Scripts principais:

ml/scripts/exportar_dados_api.py
Gera ou exporta dados brutos simulados para data/raw/certificados_simulados.csv.

ml/scripts/limpar_dados.py
Padroniza os dados brutos, ajustando status, curso, categoria, carga horária e meta. Gera data/processed/dataset_limpo.csv.

ml/scripts/gerar_relatorio_ml.py
Gera relatórios de métricas, incluindo total de registros, aprovados, rejeitados, em análise e taxa de aprovação.

ml/scripts/treinar_modelo.py
Classifica risco dos alunos e gera reports/risco_alunos.csv e models/modelo_risco_aluno.json.

6. COMANDOS DO ML LOCAL

Entre na pasta ml:

cd ml

Instale as dependências Python:

python -m pip install -r requirements.txt

Valide a sintaxe dos scripts:

python -m py_compile .\scripts\exportar_dados_api.py .\scripts\limpar_dados.py .\scripts\gerar_relatorio_ml.py .\scripts\treinar_modelo.py

Rode o pipeline completo:

python .\scripts\exportar_dados_api.py
python .\scripts\limpar_dados.py
python .\scripts\gerar_relatorio_ml.py
python .\scripts\treinar_modelo.py

Confira os resultados:

Get-Content .\reports\resumo_executivo.txt -Encoding UTF8
Get-Content .\reports\risco_alunos.csv -Encoding UTF8

Volte para a raiz:

cd ..

8. ERROS COMUNS E CORREÇÕES

Erro: Cannot find module 'nodemailer'
Causa: dependências Node ausentes.
Correção:

npm install

ou:

npm ci

Erro: Defina a variavel de ambiente DATABASE_URL
Causa: .env ausente ou DATABASE_URL não definida.
Correção: criar .env na raiz com DATABASE_URL correta.

Erro: No such file requirements/requerements
Causa: nome digitado errado.
Correto:

requirements.txt

Erro: script/exportar_dados_api.py não encontrado
Causa: pasta digitada errado.
Correto:

scripts/exportar_dados_api.py

Erro: exporta_dados_api.py não encontrado
Causa: nome do arquivo incompleto.
Correto:

exportar_dados_api.py

Erro: data/export não existe
Causa: pasta correta é exports.
Correto:

data/exports

Erro de acentuação no PowerShell
Correção:

Get-Content arquivo.txt -Encoding UTF8

13. ROTAS DE API RECOMENDADAS

POST /api/ml/executar
Executa a pipeline Python e salva resultados no banco.

GET /api/dashboard/aluno/:id
Retorna dados inteligentes do aluno.

GET /api/dashboard/coordenador/:id
Retorna dados inteligentes para coordenador.

GET /api/dashboard/superadmin
Retorna visão geral institucional.

GET /api/insights/aluno/:id
Retorna insights do aluno.

GET /api/insights/curso/:id
Retorna insights do curso.

GET /api/recomendacoes/aluno/:id
Retorna recomendações automáticas para aluno.

GET /api/riscos/alunos
Retorna classificação de risco dos alunos.
