# Checklist Entrega 2 Mobile

Use este roteiro para validar a entrega em ambiente local ou de apresentacao.

1. login como aluno: entrar no app com usuario `aluno` ativo.
2. bloqueio de admin/coordenador: tentar login com `superadmin` ou `coordenador` e confirmar bloqueio com mensagem amigavel.
3. dashboard do aluno: conferir curso ativo, progresso, horas e ultimas solicitacoes.
4. troca de curso ativo: usar aluno com mais de um curso, selecionar outro curso em `Perfil` e confirmar recarga de dashboard/atividades/status.
5. envio com PDF: preencher formulario obrigatorio, anexar PDF e enviar.
6. envio com foto da camera: autorizar camera, tirar foto, conferir pre-visualizacao e enviar.
7. envio com imagem da galeria: autorizar galeria, escolher JPG/PNG/WEBP, conferir pre-visualizacao e enviar.
8. status das solicitacoes: abrir aba `Status` e conferir titulo, categoria, carga horaria, status, data, observacao/feedback e comprovante.
9. e-mail/notificacao de confirmacao: conferir fila/tabela `emails` ou painel admin para a mensagem `Solicitacao de atividade complementar registrada`.
10. controle de acesso: tentar selecionar curso nao vinculado via API e confirmar erro; conferir que o app so lista cursos retornados para o aluno autenticado.

Resultado esperado: todos os itens acima devem passar antes de considerar a Entrega 2 Mobile pronta.
